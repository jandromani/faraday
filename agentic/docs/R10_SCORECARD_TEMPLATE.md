## Acceptance
Five independently completed scorecards, one consented operational pilot
and one independent security-review report are separate proof requirements.
An internal CI pass is insufficient to mark these completed.

For external review, do not request credentials, identifying logs, customer
information, IP addresses, production keys, browser session exports or
screenshots of private data. Store redacted artifacts with tightly scoped
access. Document all failed tests, not just successes.

The security operator must be able to disable the synthetic pilot without
removing third-party software or changing customer production policies.
